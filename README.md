# OTC Request Form

An offline demo of an over-the-counter medication request form. Choose a
fictional pharmacy, fill in a synthetic patient request, and download a sample
PDF. Use made-up patient and provider details.

## Run the demo

Install the dependencies ahead of an offline session, or use a populated npm
cache. No environment variables or accounts are needed.

```sh
npm ci
npm run dev
```

Open the local URL that Vite prints. After installing the dependencies, the
app runs offline. Drafts are stored in the browser for the selected demo
pharmacy, and PDFs are generated and downloaded locally.
